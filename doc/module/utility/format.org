#+TITLE: format
#+OPTIONS: toc:nil num:nil ^:nil
#+STARTUP: showall

* Purpose

=format.hpp= holds the three formatting layers for the utility types: a
=std::formatter= specialisation, so =std::format("{}", x)= and =std::print=
accept them, and a =to_string= and an =operator<<= that give the same text. It
is separate from the type headers because =<format>= is heavy and those headers
reach most of the library: code that only uses =flags=, =cobs= or
=strong_typedef= does not pay for it. Include =format.hpp= (or the =utility.hpp=
umbrella) where the formatting happens.

* What it provides

| type                        | output                                                                    | format spec                      |
|-----------------------------+---------------------------------------------------------------------------+----------------------------------|
| =cobs::error=               | the enumerator name                                                       | string, e.g. ={:>16}=            |
| =flags<E>=                  | the raw mask as unsigned, or the set bits' names when =E= has =to_string= | integer, e.g. ={:#x}=, or string |
| =static_string<N>=          | the content                                                               | string                           |
| =strong_typedef<Tag, T, O>= | the underlying value                                                      | whatever =T= accepts             |
| =ability=                   | the flag or group name                                                    | string                           |
| =buffer_cursor<B>=          | =buffer_cursor(position=2, size=8)=                                       | string                           |
| =lazy<F>=                   | =lazy(42)= once accessed, =lazy(pending)= before                          | string                           |
| =non_null<T>=               | =non_null(0x...)=, the address it holds                                   | string                           |
| =unique_resource<R, D>=     | =unique_resource(owns=true, handle=3)=                                    | string                           |
| =scope_guard<Fn>=           | =scope_guard(armed)= or =scope_guard(dismissed)=                          | string                           |
| =defer<Fn>=                 | =defer(armed)=                                                            | string                           |
| =function_ref<Sig>=         | =function_ref(bound)= or =function_ref(empty)=                            | string                           |
| =in_place_function<Sig, N>= | =in_place_function(bound, capacity=N)=, or =empty=                        | string                           |

=to_string(x)= returns that text as a =std::string= (the named types keep
their =constexpr= =std::string_view= =to_string=) and =operator<<= streams it.
The type guides describe each output in detail: [[file:cobs.org][cobs]], [[file:flags.org][flags]],
[[file:static_string.org][static_string]] and [[file:strong_typedef.org][strong_typedef]].

The stateful helpers print a one-line summary of what their accessors expose,
and printing never changes that state: a =lazy= that has not been accessed
prints =lazy(pending)= without running its factory, and prints =lazy(ready)=
once accessed when its value type has no formatter. =non_null= reads the
address through =std::to_address=, so a smart pointer prints the object it
points at, and a moved-from wrapper prints =non_null(null)=. =unique_resource=
prints a pointer handle as its address (never as the text a =char*= points
at) and leaves out a handle that has no formatter. The metaprogramming helpers
(=type_list=, =overloaded=, =is_strong_typedef=, =function_traits=) hold no
state and have no formatter.

* Usage

#+BEGIN_SRC cpp
#include <format>
#include <nexenne/utility/flags.hpp>
#include <nexenne/utility/format.hpp>

enum class perm : unsigned { read = 1U, write = 2U };

auto const text{std::format("{:#b}", nexenne::utility::flags{perm::read} | perm::write)};
// text == "0b11"
#+END_SRC

* Gotchas

- *Include it where you format.* Without =format.hpp= a =std::format= call on
  one of these types fails to compile, with an error about a missing
  =std::formatter=; nothing falls back silently.
- *=source_location_format= is separate.* It writes a =std::source_location=
  into a caller buffer without =<format>=; see
  [[file:source_location_format.org][source_location_format]].
