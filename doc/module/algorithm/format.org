#+TITLE: format
#+OPTIONS: toc:nil num:nil ^:nil
#+STARTUP: showall

* Purpose

=format.hpp= holds the three formatting layers for the algorithm types a caller
gets back and may want to print: a =std::formatter= specialisation, so
=std::format("{}", x)= and =std::print= accept them, and a =to_string= and an
=operator<<= that give the same text. It is separate from the algorithm headers
because =<format>= is heavy: code that only encodes, hashes or sorts does not pay
for it. Include =format.hpp= where the printing happens.

* What it provides

| type                          | output                                                | format spec           |
|-------------------------------+-------------------------------------------------------+-----------------------|
| =codec_error=                 | the enumerator name                                   | string, e.g. ={:>18}= |
| =numerical_error=             | the enumerator name                                   | string                |
| =a_star_result<V, W>=         | =a_star_result(path=[...], cost=...)=                 | none                  |
| =scc_result<V>=               | =scc_result(labels=[...], num_components=...)=        | none                  |
| =components_result<E, V>=     | =components_result(labels=[...], num_components=...)= | none                  |
| =floyd_warshall_result<V, W>= | =floyd_warshall_result(n=..., distances=[...])=       | none                  |
| =mst_edge<E, V>=              | =mst_edge(from=..., to=..., weight=...)=              | none                  |

The error enums keep their =constexpr= =std::string_view= =to_string= from
their own headers; the graph results get a =std::string= =to_string= here. Either
way =operator<<= streams the same text the formatter prints.

The compile-time configuration types (=crc_spec=, =modular_sum_spec=,
=base_n_spec=, =codec_alphabet=) and the streaming engines (=crc_ctx=,
=fnv1a_ctx=, =xxhash_ctx=) have no formatter: they are template parameters and
accumulator state, not values to show. A computed hash or checksum is a plain
integer and formats through the standard library.

* Usage

#+BEGIN_SRC cpp
#include <format>
#include <nexenne/algorithm/encoding/base_n.hpp>
#include <nexenne/algorithm/format.hpp>

namespace alg = nexenne::algorithm;

if (auto const bytes{alg::base64_decode("not base64!")}; !bytes) {
  auto const text{std::format("decode failed: {}", bytes.error())};
  // text == "decode failed: invalid_input"
}
#+END_SRC

* Gotchas

- *Include it where you print.* Without =format.hpp= a =std::format= call or a
  stream insertion on one of these types fails to compile; nothing falls back
  to the underlying integer silently.
- *Graph results print every element.* A large =floyd_warshall_result= renders
  its whole =n * n= distance matrix, so print one for debugging, not in a loop.
